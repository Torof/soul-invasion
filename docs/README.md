# Soul Invasion — Design Corpus

*Working title. Version 0.1 — November 1, 2026.*

This folder gathers the vision, lore, game systems and architecture decisions of **Soul Invasion**, produced during the design sessions.

It is the project's **shared reference**: every work session starts by re-reading these documents. Any important decision must be added or updated here.

## Contents

| File | Content |
|---|---|
| `01-vision.md` | The concept, the pillars, the game philosophy, the goals and the build charter |
| `02-lore.md` | The world, its inhabitants, the parasite souls, the Changed, religion |
| `03-game-systems.md` | The soul and reincarnation, NPCs, groups, economy, knowledge, the summits |
| `04-architecture.md` | The technical decisions, each with its reason and consequences |
| `05-first-version.md` | The scope of the first version and its five stages |
| `06-open-questions.md` | What remains to be decided, and when |
| `07-style-bible.md` | The visual identity: reference, line, palette, light, camera |
| `08-midjourney-prompts.md` | The prompts for producing scenery, animals and camp elements |
| `09-visual-production.md` | Visual production: the rendering choice, the format contract every image obeys, what is produced and when |

The validated images live in `content/art/` (content, CC BY-NC-SA), each with a note giving its prompt and date.

## Project working rules

- **Nothing is built, coded or modified without the project lead's explicit approval.**
- We discuss first, decide next, build last.
- The project lead is the **conductor**: vision, decisions, practices, audits, security. The code is written by the AI.
- These documents evolve: a changed decision is updated here, with its new reason.
- **All project documents, code, comments and identifiers are written in English**, so the project stays accessible to everyone (decided 5 November 2026).
