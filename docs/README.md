# Soul Invasion — Design Corpus

*Working title. Version 0.1 — 1 November 2026.*

This folder gathers the vision, lore, game systems and architecture decisions of **Soul Invasion**, as they came out of the design sessions.

It is the **shared reference** of the project: every work session starts by re-reading these documents. Every significant decision must be added or updated here.

## Contents

| File | Content |
|---|---|
| `01-vision.md` | The concept, the pillars, the game philosophy, the goals and the building charter |
| `02-lore.md` | The world, its inhabitants, the parasite souls, the Changed, religion |
| `03-game-systems.md` | The soul and reincarnation, NPCs, groups, economy, knowledge, the summits |
| `04-architecture.md` | The technical decisions, each with its reason and its consequences |
| `05-first-version.md` | The scope of the first version and its five milestones |
| `06-open-questions.md` | What remains to be decided, and when |

## Project rules

- **Nothing is built, coded or modified without the explicit approval** of the project lead.
- We discuss first, decide next, build last.
- The project lead is the **conductor**: vision, decisions, practices, audits, security. The code is written by the AI.
- These documents evolve: a changed decision is updated here, with its new reason.
- **All project documents, code, comments and identifiers are written in English**, so the project stays accessible to everyone (decided 5 November 2026).
